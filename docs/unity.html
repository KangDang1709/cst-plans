2. Real-Time State from Firebase

Single State Node Per Room

Listen to: exam-rooms/{examRoomId}/state

When room state changes, Lambda updates this node. You get notified of changes and extract critical data like startedAt + durationMinutes for the timer.

Example Timeline

1. You join exam (POST /join)
Lambda writes to Firebase:
exam-rooms/ABC/state = { state: "WAITING", participantCount: 15, timestamp: 1705314900000 }

Your listener receives notification → Wait for exam to start
2. Teacher starts exam
Lambda writes:
exam-rooms/ABC/state = { state: "IN_PROGRESS", startedAt: 1705315200000, durationMinutes: 90, timestamp: 1705315200000 }

Your listener receives notification → Extract startedAt + durationMinutes → Start countdown timer
3. You and others submit
Lambda updates Firebase (concurrent submissions):
exam-rooms/ABC/state = { state: "IN_PROGRESS", eventCount: 5, timestamp: 1705318500000 }

Your listener receives notification → Submission recorded (visible to teacher)
4. Teacher ends exam
Lambda writes:
exam-rooms/ABC/state = { state: "ENDED", endedAt: 1705332000000, timestamp: 1705332000000 }

Your listener receives notification → Show end screen

6. Timer Formula

Calculate remaining time on exam from startedAt + durationMinutes:

long startedAtEpoch = (long)eventData["startedAt"];
long durationMinutes = (long)eventData["durationMinutes"];
long durationMs = durationMinutes * 60_000L;

long epochNow = System.DateTimeOffset.UtcNow.ToUnixTimeMilliseconds();
long remainingMs = (startedAtEpoch + durationMs) - epochNow;

if (remainingMs <= 0) {
  // Time's up
} else {
  int remainingSeconds = (int)(remainingMs / 1000);
  StartCountdown(remainingSeconds);
}

7. Reconnect Handling

Firebase automatically handles reconnects. If connection drops:

  • Firebase SDK caches the subscription
  • On reconnect, current state is replayed
  • No manual reconnect logic needed
  • If you need latest state, call GET /exam-rooms/{id} to recover

8. Error Codes

400 Bad Request: Invalid joinCode format, missing studentId, etc.
401 Unauthorized: Access token missing, expired, or invalid.
404 Not Found: Exam room not found, or joinCode doesn't exist.
409 Conflict: Student already joined this room, or exam already ended.

9. Quick Start Flow (Student)

  1. Register → OTP email received
  2. Verify OTP → verification complete
  3. Login → Get accessToken
  4. Enter joinCode and click "Join" → POST /join
  5. Lambda writes to Firebase → Teacher sees you joined
  6. Initialize Firebase listener for exam-rooms/{examRoomId}/state
  7. Show waiting screen - "Waiting for teacher to start..."
  8. Teacher clicks Start → Firebase listener receives IN_PROGRESS state
  9. Extract startedAt + durationMinutes from state → Start countdown timer
  10. Fetch questions → GET /exam-rooms/{id}/questions
  11. Answer and submit questions → POST /submit
  12. Firebase listener notifies teacher of submission
  13. Teacher ends exam → Firebase listener receives ENDED state
  14. Show end screen

10. Unity C# Implementation (Firebase Real-Time)

Complete Sample Code

using Firebase.Database;
using UnityEngine;
using System;
using System.Collections;

public class ExamTimer : MonoBehaviour
{
    private FirebaseDatabase firebaseDb;
    private string examRoomId = "ROOM_456"; // From API response when joined
    private DatabaseReference stateRef;

    void Start()
    {
        // Subscribe to Firebase real-time updates
        firebaseDb = FirebaseDatabase.DefaultInstance;
        stateRef = firebaseDb.GetReference($"exam-rooms/{examRoomId}/state");
        
        // This listener fires EVERY time the state changes
        stateRef.ValueChanged += OnExamStateChanged;
    }

    // ============================================================
    // REAL-TIME LISTENER (Fires when state changes in Firebase)
    // ============================================================
    private void OnExamStateChanged(object sender, ValueChangedEventArgs args)
    {
        var stateData = args.Snapshot.Value as Dictionary<string, object>;
        string state = stateData["state"].ToString();

        if (state == "IN_PROGRESS")
        {
            // Teacher started the exam
            long startedAt = long.Parse(stateData["startedAt"].ToString());
            long durationMinutes = long.Parse(stateData["durationMinutes"].ToString());

            StartTimer(startedAt, durationMinutes);
        }
        else if (state == "ENDED")
        {
            // Exam ended
            StopAllCoroutines();
            Debug.Log("Exam finished");
        }
    }

    // ============================================================
    // COUNTDOWN TIMER LOGIC
    // ============================================================
    private void StartTimer(long startedAtMs, long durationMinutes)
    {
        // endTime = when exam should end
        long endTimeMs = startedAtMs + (durationMinutes * 60_000L);
        
        StartCoroutine(CountdownCoroutine(endTimeMs));
    }

    private IEnumerator CountdownCoroutine(long endTimeMs)
    {
        while (true)
        {
            long nowMs = DateTimeOffset.UtcNow.ToUnixTimeMilliseconds();
            long remainingMs = endTimeMs - nowMs;

            if (remainingMs <= 0)
            {
                Debug.Log("Time's up!");
                break;
            }

            // Display timer (MM:SS)
            int seconds = (int)(remainingMs / 1000);
            int mins = seconds / 60;
            int secs = seconds % 60;

            Debug.Log($"⏱ {mins:D2}:{secs:D2}");
            // UI.timerText.text = $"{mins:D2}:{secs:D2}";

            yield return new WaitForSeconds(1f);
        }
    }

    void OnDestroy()
    {
        stateRef.ValueChanged -= OnExamStateChanged;
    }
}

How It Works

  • OnExamStateChanged — Fired instantly when Firebase state changes (no polling)
  • startedAt + durationMinutes — Extract absolute end time from state
  • CountdownCoroutine — Use server time to calculate remaining minutes/seconds
  • Automatic reconnect — Firebase SDK handles drops and replays current state

Setup Requirements

  • Install Firebase Unity SDK from Firebase Console
  • Initialize Firebase in your scene (FirebaseApp.CheckAndFixDependenciesAsync)
  • Get examRoomId from POST /join response
  • Attach this script to a GameObject that persists during the exam
