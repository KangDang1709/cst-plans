2. Real-Time State from Firebase

Single State Node Per Room

Listen to: exam-rooms/{examRoomId}/state

Lambda updates this node whenever room state changes. Concurrent events just update the same node - last write wins. You get notified of changes, then call REST endpoints for full data.

Example Timeline

1. Teacher starts exam (POST /start)
Lambda writes to Firebase:
exam-rooms/ABC/state = { state: "IN_PROGRESS", timestamp: 1705315200000 }

FE receives notification → calls GET /participants → shows student list
2. CR7 and Messi submit simultaneously
Both POST /submit endpoints fire at same time.
Lambda updates Firebase (both target same node):
exam-rooms/ABC/state = { state: "IN_PROGRESS", eventCount: 2, timestamp: 1705318500000 }

FE receives ONE notification (not two) → calls GET /participants → sees both submissions
3. Teacher ends exam (POST /end)
Lambda writes:
exam-rooms/ABC/state = { state: "ENDED", timestamp: 1705332000000 }

FE receives notification → calls GET /results → shows leaderboard

6. Timer Formula

Calculate remaining time on exam from startedAt + durationMinutes:

const remainingMs = (startedAt + durationMinutes * 60_000) - Date.now();
const remainingSeconds = Math.max(0, Math.ceil(remainingMs / 1000));

7. Error Codes

400 Bad Request: Invalid durationMinutes, title missing, etc.
401 Unauthorized: JWT missing or expired. Re-login.
403 Forbidden: Not authorized to create/modify this room.
404 Not Found: Exam room not found.
409 Conflict: Cannot start exam that's already started.

Quick Start Flow

  1. Teacher logs in → Get JWT token
  2. Teacher creates exam room → Get joinCode & examRoomId
  3. FE initializes Firebase listener for exam-rooms/{examRoomId}/state
  4. FE shows waiting room, calls GET /participants to show student list
  5. Teacher clicks "Start" → POST /start
  6. Firebase listener notified → FE calls GET /participants again
  7. FE shows live submission count (updates when Firebase state changes)
  8. Teacher clicks "End" → Firebase listener notified
  9. FE calls GET /results → Shows leaderboard
